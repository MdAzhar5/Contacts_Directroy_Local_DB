Imports, exports and filter runs

Data updates

Foursquare, Overture and OpenStreetMap publish new releases regularly. The app checks once a day when it starts. A newer release can be downloaded and merged into All Leads: only fresh leads are added (a phone or email not already in All Leads or Used Data), the rest are skipped and counted, businesses you already have are updated in place, and your Used Data marks are kept.

Installed updates

Each installed release is a data batch. Fresh leads are stamped with their batch, so you can compare the latest batch with earlier ones: pick it under Data batch in All Leads, or click View in All Leads.

How an update runs

  1. Click Download & install. The updater opens in its own console window and this app closes so the database is free.
  2. The release is downloaded into data\ (10 to 12 GB, resumable), then USA contacts are extracted and normalized.
  3. Businesses already in All Leads (same source id) are updated if their details changed, otherwise left untouched.
  4. Every other row is a candidate. It is added only when its phone or email is not already in All Leads or Used Data. Rows with no valid phone or email, rows whose phone or email is already known, and repeats of the same phone or email inside the release are skipped and counted.
  5. Fresh leads are stamped with the update, filter tables are rebuilt, the raw download is deleted, and the app starts again showing how many fresh leads were added and how many old ones were skipped. The run appears below, under Data batch in All Leads, and in History as kind "update".

Foursquare needs a Hugging Face token in the git-ignored .env file (copy .env.example and set HF_TOKEN). Overture and OpenStreetMap need no credentials. To be told about new releases without opening the app, run pipeline\install_daily_check.bat once.
